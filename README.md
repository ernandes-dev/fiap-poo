# FiapRide - Programação Orientada a Objetos

## Sobre o projeto

Este projeto foi desenvolvido como atividade prática de Programação
Orientada a Objetos (POO) em Java.

O objeto escolhido para representar uma situação do mundo real foi
um micro-ondas.

## Classe Microondas

A classe `Microondas` representa um aparelho utilizado para aquecer
alimentos.

### Atributos

- `marca`: representa a marca do micro-ondas.
- `potencia`: representa a potência do aparelho em watts.
- `tempo`: representa o tempo de funcionamento em segundos.

## Métodos

### aquecer()

O método `aquecer()` adiciona segundos ao tempo de funcionamento
do micro-ondas.

Exemplo:

```java
microondas.aquecer(30);
